# Security

HarnessForge currently contains theory-building simulators and does not execute external tools or provision infrastructure.

## Reporting a vulnerability

Email [Vas Kuruganti](mailto:vkuruganti1@gmail.com) at `vkuruganti1@gmail.com` with the subject `HarnessForge security report`. Include the affected version or commit, reproduction steps, impact, and any suggested mitigation. Do not post vulnerability details in public issues before coordination with the maintainer.

Security fixes are developed against the latest `main`; older versions do not have a separate maintenance commitment. This volunteer project does not promise a response deadline. Coordinate disclosure and any release announcement with the maintainer.

## Scope

Please do not contribute examples that autonomously scan, compromise, or propagate across real systems. Security-sensitive work should use contained and explicitly authorized environments.
